# PDE Playground

브라우저에서 **실시간으로 편미분방정식(PDE)을 풀고 시각화**하는 인터랙티브 툴입니다.
[VisualPDE](https://visualpde.com) 에서 영감을 받아, GPU(WebGL2 fragment shader)에서
유한차분법으로 PDE 를 직접 적분합니다. 별도 빌드 과정이나 의존성이 없습니다.

![heat / wave / plate](https://img.shields.io/badge/WebGL2-realtime-58a6ff)

## 지원하는 방정식

| 방정식 | 형태 | 시간 차수 | 특징 |
|---|---|---|---|
| **열 방정식** | ∂u/∂t = D ∇²u | 1차 | 확산·평활화 |
| **파동 방정식** | ∂²u/∂t² = c² ∇²u − γ ∂u/∂t | 2차 | 파동 전파·반사 |
| **판 방정식** | ∂²u/∂t² = −D ∇⁴u − γ ∂u/∂t | 2차 | 4차(biharmonic) 분산성 진동 |

## 실행

### 방법 1 — 단일 파일 (가장 간단)

**[`pde-playground.html`](pde-playground.html)** 한 파일만 받아서 브라우저로 **더블클릭/열기** 하면 끝입니다.
모든 CSS·JS 가 인라인되어 있어 서버 없이 `file://` 로 바로 동작합니다.

### 방법 2 — 모듈 버전 (개발용)

`index.html` + `js/` + `css/` 구조는 ES 모듈을 쓰므로 정적 서버가 필요합니다.

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

> 모듈 버전(`index.html`)은 `file://` 로 직접 열면 동작하지 않습니다. 서버 없이 쓰려면 `pde-playground.html` 을 쓰세요.

### 단일 파일 다시 만들기

`js/`·`css/` 를 수정한 뒤 단일 파일을 갱신하려면:

```bash
node build.mjs   # → pde-playground.html 재생성
```

> 캐시버스팅: `index.html`은 `css/style.css?v=...`, `js/main.js?v=...`(+ `main.js`
> 내부 import의 `?v=...`)로 정적 파일 버전을 관리합니다. CSS/JS를 수정해 배포할
> 때는 이 `?v=` 값을 함께 올리면 브라우저가 새 파일을 즉시 받아갑니다.

## 사용법

- **방정식 선택** — 좌측 상단 드롭다운
- **클릭 / 드래그** — 그 위치에 교란(열·파동)을 실시간 주입 (모바일 터치 지원)
- **파라미터 슬라이더** — 확산계수, 파동속도, 감쇠, 강성 등을 즉석에서 조절
- **시각화** — 컬러맵, 대비(gain), 격자 해상도(128/256/512), 시뮬 속도, 붓 크기
- **버튼** — 일시정지 / 초기화 (화면은 빈 상태로 시작하며, 클릭해서 교란을 줍니다)

## 동작 원리 — PDE 코드는 어떻게 푸나

PDE 를 **유한차분법(finite difference)** 으로 이산화하여, 매 프레임 GPU 위에서 명시적
시간적분(explicit time stepping)을 반복하는 방식입니다. CPU 루프 없이 fragment shader
한 번의 draw 가 격자 전체(N×N 셀)를 동시에 갱신합니다.

### 1. 상태를 텍스처에 담는다

장(field)은 `N×N` 크기의 `RGBA32F` **부동소수점 텍스처**에 저장됩니다. 각 텍셀(픽셀)이
격자점 한 칸이고, 채널에 물리량을 담습니다:

| 채널 | 의미 |
|---|---|
| `R` | `u` — 장 값 (변위·온도 등) |
| `G` | `v = ∂u/∂t` — 시간 변화율 (속도). 2차 방정식에서만 사용 |

열 방정식은 1차라 `v` 가 필요 없고, 파동·판 방정식은 2차라 `u` 와 `v` 를 함께 들고 갑니다.

### 2. 공간 미분 = 이웃 텍셀의 가중합 (스텐실)

시뮬레이션은 **격자 단위**로 계산합니다(격자 간격 `dx = 1`). 따라서 미분 연산자는
주변 텍셀을 더하고 빼는 단순한 스텐실이 됩니다. 코드에서 `Uo(offset)` 는 현재 셀에서
정수 텍셀만큼 떨어진 곳의 `u` 를 읽는 헬퍼입니다.

- **라플라시안 ∇²u** — 5점 스텐실
  ```
  ∇²u ≈ u(i+1,j) + u(i−1,j) + u(i,j+1) + u(i,j−1) − 4·u(i,j)
  ```
- **중조화 ∇⁴u** (판 방정식) — 13점 biharmonic 스텐실
  ```
  ∇⁴u ≈ 20·u
        − 8·(상·하·좌·우 4개)
        + 2·(대각선 4개)
        + 1·(거리 2 떨어진 4개)
  ```

`dx = 1` 인 격자 단위를 쓰는 이유: 실제 물리 단위(예: `dx = 1/N`)를 쓰면 명시적 스킴의
안정 dt 가 극도로 작아져 확산이 눈에 보이게 퍼지는 데 수만 스텝이 필요합니다. 격자 단위로
풀고 파라미터를 거기에 맞추면 **안정적이면서도 시각적으로 생동감 있는** dt 를 쓸 수 있습니다.

### 3. 시간적분 — 다음 상태를 계산한다

`js/equations.js` 의 각 방정식이 GLSL 한 토막(`body`)으로 `newU`, `newV` 를 정의합니다.

- **열 방정식** — 전진(forward) 오일러
  ```glsl
  newU = u + dt * D * lap;          // u_{n+1} = u_n + dt·D·∇²u
  ```
- **파동 방정식** — 준음함적(symplectic) 오일러: 속도부터 갱신하고 그 값으로 위치를 갱신
  ```glsl
  newV = v + dt * (c2 * lap - γ * v);   // 가속도 = c²∇²u − 감쇠
  newU = u + dt * newV;                 // 새 속도로 변위 적분
  ```
- **판 방정식** — 위와 같은 구조에 4차 항
  ```glsl
  newV = v - dt * (D * biharm + γ * v); // 가속도 = −D∇⁴u − 감쇠
  newU = u + dt * newV;
  ```

준음함적 적분은 단순 오일러보다 에너지를 잘 보존해, 감쇠 `γ = 0` 일 때 파동이 오래
진동하도록 합니다.

### 4. Ping-pong — 두 텍스처를 번갈아 쓴다

한 텍스처를 읽으면서 동시에 같은 곳에 쓸 수는 없습니다. 그래서 텍스처 두 장(A, B)과
프레임버퍼를 두고, **A 를 읽어 B 에 쓰고 → 다음 스텝엔 B 를 읽어 A 에 쓰는** 식으로
번갈아 갱신합니다(`solver.js` 의 `step()`). 한 애니메이션 프레임마다 이 스텝을
`substeps` 번 돌려(슬라이더로 조절) 부드럽고 빠르게 진행합니다.

### 5. 경계 조건과 안정성

- **경계** — 텍스처 래핑을 `CLAMP_TO_EDGE` 로 두어, 격자 밖을 읽으면 가장자리 값을
  돌려줍니다. 이는 **노이만(zero-gradient) 경계**에 해당해 파동이 벽에서 반사됩니다.
- **안정성(CFL)** — 명시적 스킴은 dt 가 너무 크면 발산합니다. 대략
  열 `D·dt ≲ 0.25`, 파동 `c²·dt² ≲ 0.5`, 판은 ∇⁴ 의 큰 고윳값 때문에 더 작은 dt 가
  필요합니다. 각 방정식의 기본 `dt`·`substeps` 는 이 한계 안에서 정해 둡니다.

### 6. 마우스 교란 주입

포인터를 누르고 있는 동안, update shader 가 마우스 위치에 가우시안 범프를 더합니다:
```glsl
newU += amp * exp(-dist² / brush²);   // 누른 자리에 열/파동을 주입
```

### 7. 화면에 그리기 (render pass)

별도의 fragment shader 가 상태 텍스처의 `u` 를 읽어 색으로 변환합니다. 장 값은 범위가
정해져 있지 않으므로 `tanh` 로 부드럽게 `[0,1]` 로 눌러 정규화한 뒤 컬러맵을 적용합니다:
```glsl
float t = 0.5 + 0.5 * tanh(u * gain);   // gain = 대비 슬라이더
outColor = colormap(cmap, t);            // coolwarm / fire / spectral …
```
부동소수점 텍스처는 `LINEAR` 필터로 샘플링해 격자보다 큰 화면에서도 매끄럽게 보입니다.

### 요약 파이프라인

```
상태 텍스처(uₙ, vₙ)
      │  update shader ×substeps  (스텐실 → 시간적분 → 마우스 교란)
      ▼
상태 텍스처(uₙ₊₁, vₙ₊₁)   ← ping-pong 으로 A/B 교대
      │  render shader  (tanh 정규화 → 컬러맵)
      ▼
   화면(canvas)
```

## 새 방정식 추가하기

`js/equations.js` 의 `EQUATIONS` 배열에 항목을 하나 추가하면 됩니다. GLSL `body`
안에서 `u`, `v`, `lap`, `Uo(offset)`, `u_dt`, `u_time`, `u_p0..u_p3`, `v_uv` 를 사용해
`newU`, `newV` 를 정의하면 자동으로 UI(슬라이더 포함)에 연결됩니다.
